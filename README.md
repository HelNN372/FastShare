# FastShare · Быстрый перенос

Android 5.0 и новее. На обоих телефонах нужна версия FastShare 0.2 или новее. Оба участника могут отправлять и принимать файлы в одном соединении.

[Скачать подписанный APK из Releases](https://github.com/HelNN372/FastShare/releases/latest)

## По локальной сети

1. Подключи телефоны к одному Wi‑Fi или к точке доступа одного из них.
2. Открой FastShare на обоих телефонах и нажми **Включить поиск**.
3. На одном телефоне нажми на найденное устройство. Сравни шесть цифр на обоих экранах и подтверди подключение.
4. Выбери файлы или приложения и нажми **Отправить**. Получатель выбирает папку и подтверждает приём.

Android открывает системные диалоги выбора файлов и папки. Доступ выдаётся к выбранным файлам и папке. Геолокация не запрашивается. Для обнаружения нужны IPv4 и возможность обмена локальными пакетами между телефонами. Если роутер изолирует клиентов, попробуй обычную домашнюю сеть или точку доступа.

## Через интернет

1. Запусти посредник [по инструкции](relay/README.md).
2. Введи адрес этого сервера на обоих телефонах.
3. На первом нажми **Создать**, на втором вставь выданный код и нажми **Войти**. Передавай код напрямую тому, кого хочешь подключить.
4. После подключения файлы можно отправлять в обе стороны. Посредник пересылает зашифрованный поток, передаваемые файлы не сохраняет.

Сервер по умолчанию не задан. Держи приложение открытым до конца передачи. Установленные приложения передаются как APK или APKS, их внутренние данные не входят в передачу. Составные APKS требуют отдельного установщика.

## Сборка

Локально нужны JDK, Android SDK Platform 35 и Build Tools 35.0.0. Укажи путь к SDK через `ANDROID_HOME` и запусти `bash scripts/build-apk.sh`. Результат появится в `dist/FastShare.apk`.

GitHub Actions собирает тестовый APK после push. Готовый файл находится в артефакте **FastShare-APK** на странице запуска. Тестовый ключ создаётся при каждой сборке. APK в Releases подписан постоянным ключом. Для локальной сборки со своим ключом передай `FASTSHARE_KEYSTORE`, `FASTSHARE_KEY_ALIAS` и `FASTSHARE_STORE_PASSWORD` через окружение.
