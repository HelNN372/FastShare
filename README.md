# Быстрый перенос (FastShare)

Приложение для передачи файлов и приложений между телефонами по Wi‑Fi. Для получения файлов достаточно браузера. Минимальная версия отправителя — Android 5.0.

В корне есть первый готовый `FastShare.apk`. GitHub Actions собирает APK из исходников после push. Готовый файл находится в артефакте **FastShare-APK** на странице успешной сборки. Запуск вручную доступен в **Actions → Build Android APK → Run workflow**.

Локальная сборка: установи JDK, Android SDK Platform 35 и Build Tools 35.0.0, укажи путь к SDK через `ANDROID_HOME` и запусти `bash scripts/build-apk.sh`. Результат появится в `dist/FastShare.apk`.

Сборка использует новый тестовый ключ на каждом запуске. Для обновления уже установленной версии нужен APK с тем же ключом подписи.
