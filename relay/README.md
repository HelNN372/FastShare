# Сервер интернет-комнат FastShare

Требуются Python 3.9+, домен с публичным DNS, доступный TCP-порт и TLS-сертификат для этого домена от центра сертификации, которому доверяют телефоны. Настрой DNS и получи сертификат с помощью своего ACME-клиента.

Запусти процесс от отдельного пользователя с доступом на чтение сертификата и ключа:

```bash
python3 relay/relay.py \
  --cert /path/to/fullchain.pem \
  --key /path/to/privkey.pem \
  --port 47443
```

Разреши входящий TCP 47443 на сервере и у провайдера. Используй `relay.example.net:47443` в приложении, подставив свой домен. Это TLS-сокет, его следует проксировать в режиме TCP, если нужен обратный прокси. Для постоянной работы запусти процесс как службу и перезапускай его после обновления сертификата.

В комнате одновременно два участника. Ожидание второго участника длится до пяти минут. Сервер маршрутизирует поток по идентификатору, вычисленному из случайного кода комнаты, и ограничивает число одновременных соединений. Передаваемые данные шифруются в клиентах. Серверу видны сетевые адреса клиентов, время соединения и объём трафика.
